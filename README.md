# Hyperliquid Terminal

A clean, dark-themed perpetuals trading terminal powered by live Hyperliquid data. No signup, no backend — runs entirely in your browser.

## Features

- 📊 **Live candlestick charts** with volume (1m / 1h / 4h / 1D / 7d)
- 💰 **Real-time prices** for 232+ Hyperliquid perps
- 📈 **Orderbook spread** (bid/ask)
- 🔔 **Price alerts** via browser notifications
- 🔍 **Coin search** & watchlist
- 📱 **Mobile-friendly** responsive design

## Data Source

All data comes directly from the [Hyperliquid API](https://hyperliquid.xyz) via CORS-enabled public endpoints. No API key required.

## Deploy Your Own

This repo auto-deploys to Netlify via GitHub Actions. Just push to `main`.

## Local Development

Simply open `index.html` in any browser — no build step needed.
